# HR Analytics – Employee Attrition Analysis

## 📌 Overview

This project focuses on analysing employee data to understand workforce distribution, identify employee attrition patterns, and uncover factors associated with employee turnover.

The project follows an end-to-end data analytics workflow, starting with data exploration and cleaning in Excel, performing SQL analysis using MySQL, and building an interactive Power BI dashboard to present meaningful business insights.

## 📂 Dataset

- **Dataset:** IBM HR Analytics Employee Attrition Dataset
- **Total Records:** 1,470 employees
- **Total Employee Exits:** 237
- **Overall Attrition Rate:** 16.12%

The dataset contains employee-related information such as age, gender, department, job role, education, salary, job satisfaction, overtime, and attrition status.

## 🔄 Project Workflow

### 1. Data Exploration & Cleaning – Excel
- Loaded and inspected the raw dataset.
- Separated clustered data into individual columns.
- Identified missing values and inconsistencies.
- Corrected data types and prepared the dataset for analysis.

### 2. SQL Analysis – MySQL
- Imported the cleaned dataset into MySQL Server.
- Performed exploratory data analysis using SQL.
- Created and executed 14 SQL queries.
- Analysed employee demographics, departments, job roles, salary slabs, and attrition patterns.
- Extracted useful information to support business questions.

### 3. Dashboard Development – Power BI
Developed a two-page interactive dashboard:

**Page 1 – Workforce Overview**
- Total employees and employee exits.
- Overall attrition rate.
- Gender-wise attrition.
- Education, job role and marital status analysis.
- Employee tenure and job-level analysis.

**Page 2 – Attrition Insights**
- Detailed employee attrition analysis.
- Attrition patterns across different employee categories.
- Salary slab, department, gender and overtime analysis.

### 4. Documentation & Presentation

Created a consolidated project presentation containing:

Project overview and methodology.

Data cleaning and SQL analysis documentation.

Power BI dashboard screenshots.

Key findings and business insights.

Project conclusion.

## 💡 Key Results & Insights

- Identified an overall employee attrition rate of 16.12%.
- Observed gender-wise employee exits, with 150 male and 87 female employees leaving.
- Examined attrition patterns across departments, job roles, education fields, and salary slabs.
- Analysed employee tenure, job satisfaction, and overtime in relation to attrition.
- Developed an interactive dashboard to make workforce trends easier to understand and explore.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the Excel dataset to explore and review the data-cleaning process.
3. Import the cleaned dataset into MySQL Server.
4. Execute the provided SQL queries to reproduce the analysis.
5. Open the Power BI `.pbix` file using Power BI Desktop.
6. Refresh the dataset and explore both dashboard pages.

**Note:** Update the file paths and database connection settings according to your local environment.
